# Controle Café Boa Vista - Modo Rápido

Versão para testar em um novo link sem mexer no sistema atual.

## Novidades

- Tela inicial em Modo Rápido.
- Botões grandes para: Nova prova, Café entrou em depósito, Cliente vendeu café, Acertar cliente e Consultar depósitos.
- Cadastro rápido de cliente ao lançar café em depósito.
- Venda rápida de café do cliente com baixa automática do saldo e recibo.
- Movimento de hoje na tela inicial.
- Painel geral antigo continua disponível no menu como "Painel geral".

## Coolify

- Build: Dockerfile
- Porta: 8080
- Volume recomendado: /app/data

Se for testar sem mexer no sistema atual, crie outro app/link no Coolify e use outro Volume Name para não misturar bancos.
